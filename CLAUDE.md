# A demo reservation web application

# Application architecture 
Frontend for the application should be browser application

API's for the Application runtime must be dotnet and the language is C# The application that will be hosted in IIS on a Windows Server hosted on Amazon in an EC2 instance

The database is Oracle Express Edition 

Chatbot is to be powered by Anthropic and use Python for the runtime

The entire application will run from one host

# Application
Make a reservations application for vacations with a web ui that calls the dotnet API's. data will be persisted in the Oracle express database

There should be at least 4 REST API's calls as part of the demo
The application login should take any UPN and password, given I do not need real authentication.

The AI chatbot should allow bookings to made as well
